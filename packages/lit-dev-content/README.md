# `lit-dev-content`

This is the client-side project

It's served from the lit-dev-server package

## Playground Agent Tools

The playground implements [WebMCP API](https://github.com/webmachinelearning/webmcp) to let in-browser agents control the Playground state and inspect the preview.

To try out WebMCP, use [supported browser or agent client](https://github.com/webmachinelearning/webmcp/blob/main/implementation-status.md). See also [awesome-webmcp](https://github.com/webmachinelearning/awesome-webmcp) for full list of clients and community integrations.
